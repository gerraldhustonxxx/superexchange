# SuperExchange

Website informasi kurs USDT - Peso dan pengajuan pinjaman online.

## Fitur
- Update kurs USDT/IDR, USDT/PHP, PHP/IDR real-time
- Form pengajuan tukar uang
- Form pengajuan pinjaman
- Terhubung dengan CS via WhatsApp

## Teknologi
- HTML, CSS, JavaScript
- CoinGecko API & ExchangeRate API
- GitHub Pages
